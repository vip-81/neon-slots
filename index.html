什么是 NEON SLOTS？

NEON SLOTS 是一款免费的赛博朋克老虎机演示：3 个轮盘 × 3 行可见符号、8 条固定赔付线、1,000 起始虚拟筹码。它是单个 HTML 文件，HTML、CSS、JavaScript 与全部图形都内联，无需注册、无充值、无真实货币，打开网页即可游玩，也可离线运行。

游戏由浏览器 Canvas 绘制轮盘、符号与庆祝动画，使用 Web Audio 合成音效、Vibration API 提供触觉反馈；在原生 App 的 WebView 中会自动通过 Hybrid Bridge 切换为原生硬解码音频、原生震动与原生持久化，在纯浏览器中则自动降级为 Web API。NEON SLOTS 是虚构的演示品牌，不是持牌赌博运营商，面向 18 岁以上用户，仅供娱乐。

如何游玩

  1. 在开始界面点击「开始游戏」。页面是单个 HTML 文件，无需安装或登录。
  2. 用 10 / 25 / 50 / 100 四个按钮，或按数字键 1–4 选择本局下注的虚拟筹码数。
  3. 点击 SPIN、按 空格 / 回车，或在轮盘区域向上滑动。三个轮盘先加速，再匀速循环滚动，然后从左到右每隔 200ms 依次减速停止；每次停轮都有向下超调再向上回弹的物理效果。
  4. 8 条赔付线上，从最左轴开始连续相同的符号按赔付表结算到虚拟余额；中奖线与符号会高亮，并触发烟花与彩带庆祝。
  5. 可开启自动旋转连续游玩；余额不足时自动补发筹码。点击「退出」返回开始界面。

技术实现与加载性能

  • 单文件、零依赖：HTML、CSS、JavaScript 全部内联；没有外部字体、脚本、图片、CDN 或分析服务，页面加载后不发起任何子资源请求。
  • Canvas 绘制：8 种符号、轮盘条带滚动、烟花彩带粒子与霓虹发光效果全部由 Canvas 路径与渐变绘制，不依赖需下载的图片。
  • 合成音效：Web Audio API 实时合成旋转、停轮、中奖与失败音效；原生壳内可切换为原生硬解码音频。
  • 双向桥接：Hybrid Bridge 以 RequestID、时间戳与回调队列实现 JS ↔ Native 通信，含超时重试与来源校验；非原生环境自动降级为 Web Audio、Vibration、visibilitychange 与本地存储。
  • 无障碍：语义化地标、跳转链接、可见焦点样式、ARIA 标签与实时状态播报；支持 prefers-reduced-motion 减少动画。
  • 响应式：适配手机与桌面，支持触摸、鼠标与键盘三种输入。
